A console-based Hackathon Management System built in Java. Features team registration with data validation, project scoring, team search functionality, and automatic winner declaration utilizing core OOP concepts, arrays, and control structure.

CONCEPTS USED:
-> Conditional Statements
-> Loops
-> Arrays
-> Strings
-> Methods
-> Object-Oriented Programming (OOP)

STEPS TO EXECUTE:
1.Compile:
   javac HackathonSystem.java
2.Run:
   java HackathonSystem
