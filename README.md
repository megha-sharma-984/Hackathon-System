# Hackathon Management System

A console-based **mini project** developed in Java to simulate a Hackathon Management System. The application demonstrates Object-Oriented Programming (OOP) concepts by managing participant registration, team details, project scoring, team search, and winner declaration.

## Features

- Team Registration
- Participant Management
- Project Scoring
- Team Search
- Automatic Winner Declaration
- Input Validation

## Technologies Used

- Java
- Object-Oriented Programming (OOP)

## Java Concepts Demonstrated

- Conditional Statements
- Loops
- Arrays
- Strings
- Methods
- Object-Oriented Programming (OOP)

## How to Run

### Compile

```bash
javac HackathonSystem.java
```

### Run

```bash
java HackathonSystem
```
